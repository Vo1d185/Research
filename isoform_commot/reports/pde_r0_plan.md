## 0. 问题

在 COMMOT 的反应–扩散模型中，配体在稳态下从产生处向外衰减，特征长度为 λ = √(D/c)
（2D 点源的稳态游离配体正比于 K₀(d/λ)）。本研究的 cost 是 −log F(d)，F = r0 / (r0 + d)。
问题：在已知真值的模拟中，使推断的接收信号最接近真值复合物的 r0 是否随 λ 增大，r0\*/λ 是多少。
同时用同样的模拟描述 COMMOT 的 cost（dis_thr 网格）。结论只适用于这个模型世界，不能说明真实组织中的 λ。

## 1. 事先写明的假设与判断

- **假设 H：最佳 r0 随 λ 单调增大。**
- **主分析：** 稳态真值、ε = 0.1 / ρ = 10、生成的随机场、指标为 Spearman（第 5–9 节）。
- **判断规则：** 对 λ 网格的 5 个值分别选出 r0\*(λ)（第 9 节）。r0\*(λ) 的绝对值随 λ **不减**，并且最大 λ 的 r0\* **严格大于**最小 λ 的 r0\*，则 H **得到支持**；否则**不支持**。
  无论结果如何，都报告每个 λ 的 r0\*/λ。
- 只有这一个事先写明的假设。COMMOT cost 的结果和方法之间的比较只做描述，不做事先的优劣判断。
- 次要分析（t = 50 真值、ε = 0.2 / ρ = 1、RMSE、存档输入场）用同一规则各自报告，但不改变主分析的判断。

## 2. 模型与固定参数

- 模拟器：`simulation/pde.py`（重新实现报告中的方程，含配体产生项 p(x)）。速率同存档：结合 a = 1（有相互作用的对，否则 0）、解离 b = 0.001、
  配体降解 c = 0.2；受体和复合物不扩散、不降解。
- 网格同存档：[−200, 200]² 上 50 × 50 的格心网格，**格点间距 h = 8**（坐标单位）。下文长度都同时用 h 表示。
- **λ 只通过 D 改变**：c 固定为 0.2，D = c λ²。无通量边界下稳态游离配体总量 ∫L = ∫p / c，与 D 无关，
  所以改变 D 只改变配体的空间分布，不改变配体总量。改变 c 会同时改变 λ 和配体总量，本计划不做。

### 4.2 随机场的生成

**参照的依据：**
- 补充材料 §2.2："配体和受体的初始分布由多个随机带宽、随机位置的高斯分布生成"。
- Extended Data Fig. 1c 的例子：每个场有 1 至 5 个斑块，部分是椭圆形。
- 存档 case 2–10 的全部 960 个输入场：
  - 最大值为 0.990–1.000，最小正值为 0.100–0.105，即先按最大值归一化，再把低于 0.1 的值置 0；
  - 非零格点占 10.7%–43.2%，中位数 26.9%。

**每个场的生成方式**（每个配体的产生场 pᵢ、每个受体的初值 R⁰ⱼ 各生成一个）：
1. 斑块数 K 在 {1, …, 5} 中均匀抽取。
2. 每个斑块是一个各向异性高斯：
   - 中心在 [−200, 200]² 中均匀抽取；
   - 两个带宽各自在 [10, 40] 坐标单位（1.25–5 h）中均匀抽取，较大的作长轴；
   - 方向角在 [0°, 180°) 中均匀抽取；
   - 权重在 [0.5, 1] 中均匀抽取。
3. 在格点中心上求加权和 f，再令 f ← f / max f，最后把 f < 0.1 的值置 0。

**随机种子：**
- 结构 c、重复 s 的一组场用 `numpy.random.default_rng([c, s])`。
- 抽取顺序：先配体 1…n，再受体 1…m。每个场内先抽 K，然后逐个斑块依次抽中心 x、中心 y、两个带宽、方向角、权重。
- 同一组场用于全部 λ 和全部 OT 条件（配对设计），不同 λ 之间只有 D 不同。

**重复次数：** 每个"结构 × λ"做 **S = 5** 次重复（s = 1–5），共 45 组场。存档每个 case 做 10 次；减少的原因是计算量（第 11 节），需要确认。

**生成器校准**（确认后、在任何 PDE 或 OT 之前做一次）：生成全部 45 组场，统计非零格点比例。
- 中位数在 [0.20, 0.35] 内：不做调整。
- 否则：把带宽范围乘以同一个系数，使中位数最接近存档的 0.269；只调整一次，并在计划中记录系数，此后固定。

## 5. 真值

### 5.1 主分析：稳态

**真值的计算：** 用 `steady_state()` 的解析形式。
- 游离配体由稀疏直接求解 (c − D∇²)Lᵢ = pᵢ 得到；然后 Rⱼ = R⁰ⱼ / (1 + Σᵢ Kᵢⱼ Lᵢ)，Cᵢⱼ = Kᵢⱼ Lᵢ Rⱼ，其中 K = a / b。
- 在守恒量 R + ΣC = R⁰ 给定时，这是从存档初始条件（L = 0、R = R⁰、C = 0）出发能到达的唯一定常解。

**收敛标准（全部满足才使用）：**
1. **线性求解：** 每个配体满足 ‖(c − D∇²)Lᵢ − pᵢ‖∞ ≤ 1e-10 ‖pᵢ‖∞，并且 Lᵢ ≥ 0。每组场、每个 λ 都检查。
2. **守恒：** 每个受体满足 ‖Rⱼ + Σᵢ Cᵢⱼ − R⁰ⱼ‖∞ ≤ 1e-12 ‖R⁰ⱼ‖∞。每组场、每个 λ 都检查。
3. **复合物浓度的动力学收敛：** 对每个结构的 s = 1、每个 λ（共 45 次）做时间积分，确认解析稳态就是动力学的终点。
   - **积分设置：** 从存档初始条件出发，用 `solve_ivp` 的 BDF 方法（提供稀疏雅可比结构），rtol 1e-10、atol 1e-14；以 Δt = 1/b = 1000 为一段积分。
   - **收敛判据：** 对每个复合物场，一段内的最大变化不超过该场最大值的 1e-8，即
     maxₓ |Cᵢⱼ(t + Δt) − Cᵢⱼ(t)| ≤ 1e-8 · maxₓ Cᵢⱼ(t + Δt)。t 最多积分到 10⁶。
   - **与解析稳态比较：** 满足判据时，要求 maxₓ |Cᵢⱼ(t) − C\*ᵢⱼ| ≤ 1e-5 · maxₓ C\*ᵢⱼ 对所有配对成立。

**不满足时：** 任何一项不满足就停下来报告，不用解析稳态做真值，等确认后再定。

### 5.2 次要分析：存档的时刻 t = 50

- 存档的 100 次模拟都在 t = 50 停止，评价也用 t = 50。
- 从存档初始条件出发，用 RK45 积分到 t = 50（与存档的 py-pde `ScipySolver` 相同），rtol 1e-8、atol 1e-10。
  重新实现时，这个设置使存档 case 2、6、10 的结果一致到 1.5e-6 以内。
- 如果在大 D 下 RK45 的步数超过 10⁶，改用 BDF，容差相同，并记录。
- D 不同时，t = 50 在动力学中的位置也不同；这是存档的做法，照用。

**真值时刻不改变 OT 的输入：** 同一份 OT 结果分别和两种真值比较，次要分析不需要另外跑 OT。

## 6. 交给 OT 的输入（按存档 `benchmark_cot.py`）

- **spot：** 2500 个格点中心，坐标用坐标单位。
- **配体 i 的表达：** 产生场 pᵢ（存档的 `ligand_prod_i`），不是游离配体 L。
- **受体 j 的表达：** 受体初值 R⁰ⱼ（存档的 `receptor_init_j`），不是游离受体 R。
- **LR 对：** 该结构中 aᵢⱼ > 0 的全部配对，都按扩散型处理，没有 contact 配对。
- **预算归一化：** 同第二阶段，求解前除以 max(Σa, Σb)，求解后乘回原单位。
- **接收信号：** 配对 (i, j) 在格点 y 的接收信号 Sᵢⱼ(y) = Σₓ Tᵢⱼ(x, y)，用原单位。
  OT 中受体 j 在 y 收到的总量不超过 R⁰ⱼ(y)，真值 Σᵢ Cᵢⱼ(y) 也不超过 R⁰ⱼ(y)，两者尺度相同，计算 RMSE 时不做缩放。

### 7.1 本研究的 cost

| 条件 | F(d) | cost | 网格 |
|---|---|---|---|
| O-inv | min(h / d, 1)（第一阶段的 inverse 核，参考距离取最近邻间距 h）；d = 0 时为 1 | max(log(d / h), 0) | — |
| O-r0 | r0 / (r0 + d) | log1p(d / r0) | r0 / λ ∈ {1/8, 1/4, 1/2, 1, 2, 4, 8}（7 个值） |

- **截断：** O-inv 和 O-r0 都用 d ≤ 4λ。
  - 截断不是研究对象。在 d = 4λ 处，点源稳态配体 K₀(4) 只有 d = λ 处 K₀(1) 的 2.7%，超出部分的真值相互作用可以忽略。
  - 同一个 λ 下全部 r0 用同一截断。λ 最大时 4λ = 506，接近格点间最大距离（554），几乎包含全部点对。
- **不缩放 cost：** 同第二阶段 A。
- **r0 网格对齐：** λ 每级加倍、r0/λ 也按 2 倍取值，所以全部 r0 落在同一组绝对值 λ_A · 2ⁿ（n = −5 … 5，即 0.12 h 至 126 h）上，
  不同 λ 的 r0\* 可以直接按绝对值比较。

### 7.2 COMMOT 的 cost

- **Cd：** cost 为 d / cost_scale（cost_scale 是截断内最大的点间距离，COMMOT 内部的归一化），纯 collective（`cot_sparse`，同第二阶段 B）。
- **dis_thr 网格：** dis_thr / λ ∈ {1, 2, 4}，再加 **dis_thr = 150**（存档 benchmark 的设定，所有 λ 都用这个值，作为"按原文"的设置）。
- **跳过的条件：** dis_thr 小于 h 时只有 d = 0 的点对，cost_scale = 0，无法计算。这只出现在 k = −2、dis_thr = λ（0.99 h），该条件跳过并记录。

主设置 ε = 0.1、ρ = 10；敏感性分析 ε = 0.2、ρ = 1。O-inv、O-r0、Cd 两种设置都跑。ε 为绝对值，两种 cost 相同，同第二阶段。

## 8. 指标（按存档 `evaluate_result_*.py`）

**单个配对：** 对每组场中的每个配对 (i, j)，只在 R⁰ⱼ > 0 的格点上比较真值 Cᵢⱼ 和接收信号 Sᵢⱼ：
- **Spearman：** 用 `scipy.stats.spearmanr`；结果为 NaN 时记为 0（同存档），并报告这类情况的个数。
- **RMSE：** √(mean((Cᵢⱼ − Sᵢⱼ)²))，用原值。

**汇总：** 层层取平均。
1. 一组场：对全部配对取平均（同存档）。
2. 一个结构：对 S 次重复取平均。
3. 一个 λ：对 9 种结构等权取平均。

**哪个指标选 r0：** 选 r0 用 Spearman（与尺度无关；第二阶段的评价也基于秩）。RMSE 是次要指标，用它选出的 r0 记为 r0\*_RMSE（取最小）。

## 9. 选择 r0\*，判断 H

**选出 r0\*：** 主分析中，对每个 λₖ，r0\*(λₖ) = 7 个 r0/λ 值中 λ 层面平均 Spearman 最大的那个；完全相等时取较小的 r0。
报告每个 λ 的 r0\*/λ 和 r0\* 的绝对值（以 h 为单位）。

**判断 H：** 用第 1 节的规则。因为网格对齐，r0\*/λ 在全部 λ 上相同，就意味着 r0\* 每级加倍。
此时写作"在网格分辨率内 r0\* 与 λ 成正比"，H 也得到支持。

**边界：** 某个 λ 的 r0\*/λ 落在网格端点（1/8 或 8）时，标为"在边界"（真正的最佳值可能在网格外）。
判断仍按网格值进行，并写明这一点。扩展网格需要先补一条计划。

**不确定性：**
- **bootstrap：** 在每个结构内对 S 次重复有放回重抽，各结构独立，共 1000 次，`numpy.random.default_rng(1)`。
  每次重抽都重新计算 λ 层面的平均和 r0\*。
- 报告每个 λ 下 r0\*/λ 落在各网格值上的比例，以及满足 H 判断规则的重抽比例。
- 报告各条件平均 Spearman 和 RMSE 的 bootstrap 标准误。

**分结构的描述：**
- 9 种结构各自的 r0\*(λ)，以及其中满足 H 判断规则的结构个数。
- 在 45 个"结构 × λ"上，log₂ λ 与 log₂ r0\* 的 Kendall τ（只做描述）。

**次要分析：**
- 分别用 t = 50 真值、ε = 0.2 / ρ = 1、RMSE、存档输入场（若运行）重复上面的选择和判断，各自报告。
- 主分析与次要分析的结论不一致时，照实写出哪些设置下成立。

**COMMOT：** 每个 λ 在 dis_thr / λ ∈ {1, 2, 4} 中选出平均 Spearman 最大的 dis_thr\*，报告 dis_thr\*/λ（只做描述）。dis_thr = 150 单独报告。

**方法的描述性比较：** 每个 λ 下比较下列 5 种设置的平均 Spearman、RMSE 及其 bootstrap 标准误。
- O-r0 在 r0\* 处（用同一数据选出，结果偏高）；
- O-r0 在 r0/λ = 1 处（事先固定，不经选择）；
- O-inv；
- Cd 在 dis_thr\* 处（同样经选择）；
- Cd 在 dis_thr = 150 处。

报告中写明哪些值是经过选择的。

## 10. 收敛与检查（OT）

- **收敛标准：** 同第二阶段修订后的 8.7。
  - **硬性要求：** 两项质量守恒检查在 1e-7 内通过，截断外的质量为 0。
  - **迭代上限：** 碰到上限只记录，不算失败。
- **稳定性诊断：**
  - 对象：结构 case 2、s = 1，在 λ₋₂ 和 λ₂ 下，O-r0（r0/λ = 1/8 和 8）和 Cd（dis_thr = 4λ）共 6 个运行。
  - 做法：用 nitermax 200000 重跑，与 50000 次的结果比较。
  - 标准：每个配对的接收信号相对 L1 差 ≤ 1e-3、Spearman ≥ 0.999，总运输量相对差 ≤ 1e-3，同第二阶段。
  - 不满足时：停下来报告，等确认（重跑这一族的计算量很大）。
- **流程核对：**
  - 在存档输入（case 2–10，sim 1–10）上运行参照条件 R，与存档自己的 `cot/adata.h5ad` 逐配对比较接收信号。
  - 标准：相对 L1 ≤ 1e-3，Spearman ≥ 0.999。
  - 不满足时：报告差别（可能来自 COMMOT 版本不同），但不阻止主分析，因为主分析用的是本研究固定的求解器。
- **指标实现核对（单元测试）：** 用存档评价脚本的规则，在一组存档模拟上，由存档的 PDE 结果和存档的 COT 输出算出 Spearman 和 RMSE，
  与本研究的指标函数结果逐配对完全一致。

## 12. 需要确认的事项

1. **重复次数：** S = 5（存档为 10）。S = 3 可以把第 1 级的时间缩短到约 2.5–5 天。
2. **本研究 cost 的截断：** 用 4λ（不限制相互作用范围），还是像第二阶段那样所有 λ 都用固定值（如 150）。
3. **网格：** r0/λ 用 1/8–8 的 7 个值；COMMOT 用 dis_thr/λ ∈ {1, 2, 4} 加 150。
4. **场生成器的参数**（第 4.2 节）和校准规则。
5. **第 3 级**（存档输入场）是否运行。

## 13. 事先说明的局限

- **场的尺度固定：** 场生成器的空间尺度固定（带宽 1.25–5 h），λ 从 1 h 变到 16 h。r0\*/λ 可能还取决于"场的尺度 / λ"，本计划不改变场的尺度。
- **λ 只通过 D 改变：** c 固定为 0.2，λ 只靠 D 改变。
- **配体预算：** OT 的配体预算是产生速率，不是浓度（存档的做法）。配体与受体预算的相对大小影响运输比例。
- **最小的 λ：** λ ≈ h 时网格分辨不了配体的衰减。
- **适用范围：** 只有一种速率组合（a、b 固定），结论只适用于这个模型。
