## 0. 问题

**背景：** 在 COMMOT 的反应–扩散模型中，配体在稳态下从产生处向外衰减，特征长度为 λ = √(D/c)；2D 点源的稳态游离配体正比于 K₀(d/λ)。
本研究的 cost 是 −log F(d)，F = r0 / (r0 + d)。

**问题：** 在已知真值的模拟中，使推断的接收信号最接近真值复合物的 r0，是否随 λ 增大？r0\*/λ 是多少？
同时用同样的模拟描述 COMMOT 的 cost（dis_thr 网格）。

**适用范围：** 结论只适用于这个模型世界，不能说明真实组织中的 λ。

## 1. 事先写明的假设与判断

- **假设 H：最佳 r0 随 λ 单调增大。**
- **主分析：** 稳态真值、ε = 0.1 / ρ = 10、生成的随机场、指标为 Spearman（第 5–9 节）。
- **判断规则：** 对 λ 网格的 5 个值分别选出 r0\*(λ)（第 9 节）。满足以下两条则 H **得到支持**，否则**不支持**：
  1. r0\*(λ) 的绝对值随 λ **不减**；
  2. 最大 λ 的 r0\* **严格大于**最小 λ 的 r0\*。

  无论结果如何，都报告每个 λ 的 r0\*/λ。
- **其他结果只做描述：** 只有这一个事先写明的假设。COMMOT cost 的结果、方法之间的比较和 bootstrap 置信区间都只做描述，不做事先的优劣判断，也不参与假设判断。
- **次要分析：** t = 50 真值、ε = 0.2 / ρ = 1、RMSE。用同一规则各自报告，但不改变主分析的判断。

## 2. 模型与固定参数

- **模拟器：** `simulation/pde.py`，即重新实现报告中的方程，含配体产生项 p(x)。
- **速率（同存档）：** 结合 a = 1（有相互作用的对，否则为 0）；解离 b = 0.001；配体降解 c = 0.2；受体和复合物不扩散、不降解。
- **网格（同存档）：** [−200, 200]² 上 50 × 50 的格心网格，**格点间距 h = 8**（坐标单位）。下文的长度都同时用 h 表示。
- **λ 只通过 D 改变：** c 固定为 0.2，D = c λ²。
  - 无通量边界下，稳态游离配体总量 ∫L = ∫p / c，与 D 无关。所以改变 D 只改变配体的空间分布，不改变配体总量。
  - 改变 c 会同时改变 λ 和配体总量，本计划不做。

### 4.2 随机场的生成与校准

**参照的依据：**
- **补充材料 §2.2：** "配体和受体的初始分布由多个随机带宽、随机位置的高斯分布生成"。
- **Extended Data Fig. 1c 的例子：** 每个场有 1 至 5 个斑块，部分是椭圆形。
- **存档 case 2–10 的全部 960 个输入场：**
  - 最大值为 0.990–1.000；
  - 最小正值为 0.100–0.105；
  - 非零格点占 10.7%–43.2%，中位数 26.9%；
  - 平顶：最多 6.8% 的格点 ≥ 0.999 × 最大值。

**场的形式**（由上述统计量确定，写计划前已看到）：

f = min(Σₖ Gₖ, 1)，然后把 f < 0.1 的值置 0。

- **Gₖ：** 峰值为 1 的各向异性高斯。
  - 中心在 [−200, 200]² 中均匀抽取；
  - 两个轴的带宽各自在 [σ_lo, σ_hi] 中均匀抽取；
  - 方向角在 [0°, 180°) 中均匀抽取。
- **斑块数：** K 在 {1, …, K_max} 中均匀抽取。
- **为什么不用"按最大值归一化"：** 那种形式的最大值总是恰好为 1，而存档中有最大值小于 1 的场。
- **为什么斑块权重固定为 1：** 用随机权重时，不重叠的场最大值会远低于 0.990。
- 每个配体的产生场 pᵢ、每个受体的初值 R⁰ⱼ 各生成一个场。

**校准：只做一次，只用存档输入场的统计量，不用任何 PDE 或 OT 结果。**

*统计量：* 在存档 case 2–10、sim 1–10 的输入场上，和在校准样本上，用同样的方法计算：
1. **非零区域比例：** 每个场中 f > 0 的格点比例。
2. **团块个数：** 每个场中 {f > 0} 的连通分量个数（`scipy.ndimage.label`，四邻接）。
3. **配体和受体重叠：** 每个场景中的每个相互作用对 (i, j)，受体非零格点中同时是配体非零格点的比例 |S(pᵢ) ∩ S(R⁰ⱼ)| / |S(R⁰ⱼ)|。

*校准样本：*
- 与存档规模相同：每种结构 10 个场景，共 90 个。
- 种子为 `numpy.random.default_rng([c, 1000 + s])`，s = 1–10。
- 与正式场景的种子（s = 1–5，见下）不重叠。

*参数网格（全部组合，共 120 个）：*
- K_max ∈ {1, …, 10}；
- σ_hi ∈ {20, 30, 40, 50, 60, 80}（坐标单位）；
- σ_lo / σ_hi ∈ {0.25, 0.5}。

*目标与选择：*
- 目标：三个统计量的双样本 Kolmogorov–Smirnov 统计量（`scipy.stats.ks_2samp`）之和，取最小。
- 完全相等时，取网格顺序中靠前的组合（K_max 从小到大、σ_hi 从小到大、比值从小到大）。

*校准之后：*

## 5. 真值

### 5.1 主分析：稳态

**真值的计算：** 用 `steady_state()` 的解析形式。
- 游离配体由稀疏直接求解 (c − D∇²)Lᵢ = pᵢ 得到；
- Rⱼ = R⁰ⱼ / (1 + Σᵢ Kᵢⱼ Lᵢ)，Cᵢⱼ = Kᵢⱼ Lᵢ Rⱼ，其中 K = a / b。

在守恒量 R + ΣC = R⁰ 给定时，这是从存档初始条件（L = 0、R = R⁰、C = 0）出发能到达的唯一定常解。

**收敛标准（全部满足才使用）：**
1. **线性求解：** 每个配体满足 ‖(c − D∇²)Lᵢ − pᵢ‖∞ ≤ 1e-10 ‖pᵢ‖∞，并且 Lᵢ ≥ 0（允许舍入误差：min Lᵢ ≥ −1e-12 · max Lᵢ；实现时补充，运行之前）。每个场景、每个 λ 都检查。
2. **守恒：** 每个受体满足 ‖Rⱼ + Σᵢ Cᵢⱼ − R⁰ⱼ‖∞ ≤ 1e-12 ‖R⁰ⱼ‖∞。每个场景、每个 λ 都检查。
3. **复合物浓度的动力学收敛：** 对每个结构的 s = 1、每个 λ（共 45 次）做时间积分，确认解析稳态就是动力学的终点。
   - **积分设置：** 从存档初始条件出发，用 `solve_ivp` 的 BDF 方法（提供解析的稀疏雅可比），rtol 1e-10、atol 1e-14。以 Δt = 1/b = 1000 为一段积分。
   - **收敛判据：** 对每个复合物场，一段内的最大变化不超过该场最大值的 1e-8，即 maxₓ |Cᵢⱼ(t + Δt) − Cᵢⱼ(t)| ≤ 1e-8 · maxₓ Cᵢⱼ(t + Δt)。t 最多积分到 10⁶。
   - **与解析稳态的一致性：** 满足判据时，要求对所有配对 maxₓ |Cᵢⱼ(t) − C\*ᵢⱼ| ≤ 1e-5 · maxₓ C\*ᵢⱼ。

**不满足时：** 任何一项不满足就停下来报告，不用解析稳态做真值，等确认后再定。

### 5.2 次要分析：存档的时刻 t = 50

- **为什么是 t = 50：** 存档的 100 次模拟都在 t = 50 停止，评价也用 t = 50。
- **积分设置：** 从存档初始条件出发，用 RK45 积分到 t = 50（与存档的 py-pde `ScipySolver` 相同），rtol 1e-8、atol 1e-10。
  重新实现时，这个设置使存档 case 2、6、10 的结果一致到 1.5e-6 以内。
- **大 D 时：** 如果 RK45 的步数超过 10⁶，改用 BDF，容差相同，并记录。
- D 不同时，t = 50 在动力学中的位置也不同；这是存档的做法，照用。

**真值与 OT 互不依赖：**
- 同一份 OT 结果分别和两种真值比较，次要分析不需要另外跑 OT。
- OT 也不依赖真值，所以两者可以同时运行。只是在第 5.1 节的检查全部通过之前，不做任何评价。

## 6. 交给 OT 的输入（按存档 `benchmark_cot.py`）

- **spot：** 2500 个格点中心，坐标用坐标单位。
- **配体 i 的表达：** 产生场 pᵢ（存档的 `ligand_prod_i`），不是游离配体 L。
- **受体 j 的表达：** 受体初值 R⁰ⱼ（存档的 `receptor_init_j`），不是游离受体 R。
- **LR 对：** 该结构中 aᵢⱼ > 0 的全部配对，都按扩散型处理，没有 contact 配对。
- **预算归一化：** 同第二阶段，求解前除以 max(Σa, Σb)，求解后乘回原单位。
- **接收信号：** 配对 (i, j) 在格点 y 的接收信号 Sᵢⱼ(y) = Σₓ Tᵢⱼ(x, y)，用原单位。
- **尺度：** OT 中受体 j 在 y 收到的总量不超过 R⁰ⱼ(y)，真值 Σᵢ Cᵢⱼ(y) 也不超过 R⁰ⱼ(y)。两者尺度相同，计算 RMSE 时不做缩放。

### 7.1 本研究的 cost

| 条件 | F(d) | cost | 网格 |
|---|---|---|---|
| O-inv | min(h / d, 1)（第一阶段的 inverse 核，参考距离取最近邻间距 h）；d = 0 时为 1 | max(log(d / h), 0) | — |
| O-r0 | r0 / (r0 + d) | log1p(d / r0) | r0 / λ ∈ {1/8, 1/4, 1/2, 1, 2, 4, 8}（7 个值） |

- **截断：** O-inv 和 O-r0 都用 d ≤ 4λ（确认决定）。
  - 截断不是研究对象。在 d = 4λ 处，点源稳态配体 K₀(4) 只有 d = λ 处 K₀(1) 的 2.7%，超出部分的真值相互作用可以忽略。
  - 同一个 λ 下全部 r0 用同一截断。λ 最大时 4λ = 506，接近格点间最大距离（554），几乎包含全部点对。
- **不缩放 cost：** 同第二阶段 A。
- **r0 网格对齐：** λ 每级加倍、r0/λ 也按 2 倍取值，所以全部 r0 落在同一组绝对值 λ_A · 2ⁿ（n = −5 … 5，即 0.12 h 至 126 h）上，
  不同 λ 的 r0\* 可以直接按绝对值比较。

### 7.2 COMMOT 的 cost

- **Cd：** cost 为 d / cost_scale（cost_scale 是截断内最大的点间距离，COMMOT 内部的归一化），纯 collective（`cot_sparse`，同第二阶段 B）。
- **dis_thr 网格：** dis_thr / λ ∈ {1, 2, 4}，再加 **dis_thr = 150**（存档 benchmark 的设定，所有 λ 都用这个值，作为"按原文"的设置）。
- **跳过的条件：** dis_thr 小于 h 时只有 d = 0 的点对，cost_scale = 0，无法计算。这只出现在 k = −2、dis_thr = λ（0.99 h），该条件跳过并记录。
- **Cd 的运行在各 λ 之间共用（实现时补充，运行之前）：**
  - Cd 的运输只取决于绝对 dis_thr，与 λ 无关；只有真值取决于 λ。
  - 所以相同绝对 dis_thr 的 Cd 条件只运行一次，在各 λ 下与对应的真值比较。例如 λ₀ 的 2λ 与 λ₁ 的 1λ 是同一个运行。
  - 求解是确定的，结果与分别运行完全相同。
  - 每个场景、每种 ε/ρ 共 7 个不同的 dis_thr：15.8、31.6、63.2、126.5、253、506，以及 150。
- **只比较 cost 时的配对（确认决定）：** 与 O-inv、O-r0 配对的是 **Cd（dis_thr = 4λ）**。
  两者截断相同，允许的点对相同（d ≤ 4λ，且只在配体和受体预算都非零的格点之间），ε、ρ、求解设置相同，唯一的差别是 cost。

## 8. 指标（按存档 `evaluate_result_*.py`）

**单个配对：** 对每个场景中的每个配对 (i, j)，只在 R⁰ⱼ > 0 的格点上比较真值 Cᵢⱼ 和接收信号 Sᵢⱼ：
- **Spearman：** 用 `scipy.stats.spearmanr`。结果为 NaN 时记为 0（同存档），并报告这类情况的个数。
- **RMSE：** √(mean((Cᵢⱼ − Sᵢⱼ)²))，用原值。

**汇总：**
1. 一个场景：对全部配对取平均（同存档）。
2. 一个结构：对 S 次重复取平均。
3. 一个 λ：对 9 种结构等权取平均。

**选 r0 的指标：**
- 主指标是 Spearman：它与尺度无关，第二阶段的评价也基于秩。
- RMSE 是次要指标，用它选出的 r0 记为 r0\*_RMSE（取最小）。

## 9. 选择 r0\*，判断 H

**选出 r0\*：** 主分析中，对每个 λₖ，r0\*(λₖ) = 7 个 r0/λ 值中 λ 层面平均 Spearman 最大的那个；完全相等时取较小的 r0。
报告每个 λ 的 r0\*/λ，以及 r0\* 的绝对值（以 h 为单位）。

**判断 H：** 用第 1 节的规则。因为网格对齐，若 r0\*/λ 在全部 λ 上相同，r0\* 就每级加倍；
此时写作"在网格分辨率内 r0\* 与 λ 成正比"，H 也得到支持。

**边界：** 某个 λ 的 r0\*/λ 落在网格端点（1/8 或 8）时，标为"在边界"，因为真正的最佳值可能在网格外。
判断仍按网格值进行，并写明这一点。扩展网格需要先补一条计划。

**按场景 bootstrap（确认决定；只做描述，不参与假设判断）：**
- **重抽方式：** 每种结构内对它的 5 个场景有放回重抽，各结构独立，共 1000 次，`numpy.random.default_rng(1)`。
- **每次重抽：** 重新计算 λ 层面的平均和 r0\*(λ)/λ。
- **r0\*/λ 的置信区间：** 每个 λ 下，1000 个 r0\*/λ 值的 2.5% 与 97.5% 分位数，结果是网格值组成的区间。
  同时报告 r0\*/λ 落在各网格值上的比例，以及满足 H 判断规则的重抽比例。
- 各条件平均 Spearman 和 RMSE 的 bootstrap 标准误，用同样的重抽。

**分结构的描述：**
- 9 种结构各自的 r0\*(λ)，以及其中满足 H 判断规则的结构个数。
- 在 45 个"结构 × λ"上，log₂ λ 与 log₂ r0\* 的 Kendall τ（只做描述）。

**次要分析：**
- 分别用 t = 50 真值、ε = 0.2 / ρ = 1、RMSE，重复上面的选择、判断和置信区间，各自报告。
- 主分析与次要分析的结论不一致时，照实写出哪些设置下成立。

**COMMOT：** 每个 λ 在 dis_thr / λ ∈ {1, 2, 4} 中选出平均 Spearman 最大的 dis_thr\*，报告 dis_thr\*/λ（只做描述）。dis_thr = 150 单独报告。

**只比较 cost（描述）：** 每个 λ、每个场景，计算 O-r0 与 Cd（dis_thr = 4λ）的平均 Spearman 之差、RMSE 之差，并报告它们的平均和按场景 bootstrap 的 95% 区间。
O-r0 取两个值：r0\*（经选择）和 r0/λ = 1（事先固定，不经选择）。O-inv 与 Cd（4λ）也做同样的比较。

**方法的描述性比较：** 每个 λ 下比较下列设置的平均 Spearman、RMSE 及其 bootstrap 标准误：
- O-r0 在 r0\* 处（用同一数据选出，结果偏高）；
- O-r0 在 r0/λ = 1 处；
- O-inv；
- Cd 在 dis_thr\* 处（同样经选择）；
- Cd 在 4λ 处；
- Cd 在 150 处。

报告中写明哪些值是经过选择的。

## 10. 收敛与检查（OT）

**收敛规则：** 沿用第二阶段修订后的 8.7（确认决定）。
- **硬性要求：** 两项质量守恒检查在 1e-7 内通过，截断外的质量为 0。不满足的运行不进入评价，并报告。
- **迭代上限：** 迭代次数和最终停止量照实记录，碰到上限本身不算失败。

**稳定性诊断：** 事先选定 3 个运行，用 nitermax = 200000 重跑，与 50000 次的主运行比较。

| 诊断 | 场景 | λ | 条件 | 选择理由 |
|---|---|---|---|---|
| D1 | 结构 6，s = 1 | λ₋₂ | O-r0，r0/λ = 1/8 | 绝对 r0 最小 |
| D2 | 结构 6，s = 1 | λ₂ | O-r0，r0/λ = 8 | 绝对 r0 最大 |
| D3 | 结构 6，s = 1 | λ_A | Cd，dis_thr = 4λ | COMMOT cost，只比较 cost 时的配对条件 |

- **为什么选结构 6：** 5 × 5、10 个配对的环状结构，是中等规模的竞争结构；D2 约 5.2M 个元素。
- **为什么不需要保存第 50000 次的 T：** 同第二阶段 8.7 的理由——迭代是确定的，nitermax 只决定何时停止。
  第二阶段已经验证了两次相同运行的 T 完全一致。
- **标准（同 8.7）：** 每个配对的接收信号在 50000 次与 200000 次之间相对 L1 差 ≤ 1e-3、Spearman ≥ 0.999，总运输量相对差 ≤ 1e-3。
- **全部满足：** 接受所有 50000 次的结果。
- **不满足：** 把未满足的那一族在 ε = 0.1 / ρ = 10 下用 200000 次重跑。O 族指 O-inv 和 O-r0，Cd 族指 Cd。
  只有碰到 50000 次上限的运行需要重跑，没碰到上限的运行重跑结果相同。

**流程核对：**
- **做法：** 在第 4.3 节的 9 个存档输入场上运行参照条件 R，与存档自己的 `cot/adata.h5ad` 逐配对比较接收信号。
- **标准：** 相对 L1 ≤ 1e-3，Spearman ≥ 0.999。
- **不满足时：** 报告差别（可能来自 COMMOT 版本不同），但不阻止主分析，因为主分析用的是本研究固定的求解器。

**指标实现核对（单元测试）：** 在一组存档模拟上，按存档评价脚本的规则，由存档的 PDE 结果和存档的 COT 输出算出 Spearman 和 RMSE；
本研究的指标函数必须给出逐配对完全一致的结果。

## 13. 事先说明的局限

- **生成场与存档场不完全一致：** 生成场的非零区域比例比存档场分散得多（KS 0.29），K_max 落在校准网格的端点（第 4.2 节）。
- **场的尺度固定：** 场生成器的空间尺度在校准后固定，λ 从 1 h 变到 16 h。r0\*/λ 可能还取决于"场的尺度 / λ"，本计划不改变场的尺度。
- **λ 只通过 D 改变：** c 固定为 0.2。
- **配体预算：** OT 的配体预算是产生速率，不是浓度（存档的做法）。配体与受体预算的相对大小影响运输比例。
- **最小的 λ：** λ ≈ h 时网格分辨不了配体的衰减。
- **适用范围：** 只有一种速率组合（a、b 固定），结论只适用于这个模型。
- **存档场的比较规模：** 只做 9 个场景，并且只在 λ_A 下。
