## 1. 定义

- **条件**：
  - C = COMMOT 原版（四方案混合，ε = 0.1，ρ = 10，教程截断 500 像素 ≈ 363 µm）；
  - B = COMMOT 纯 collective；
  - A = 本研究稀疏求解，r₀ = 50/100/200/400 µm；
  - F = 平坦核；
  - I = 反向核；
  - 只用受体表达 = 用受体表达代替接收信号；
  - C726 = C 的设置，但截断用原文的 1000 像素 ≈ 726 µm（第 8.12 节，补充）。

  这些条件的定义见 `reports/stage2_plan.md` 第 8.1、9 节。
- **接收信号**：每个 spot 从所有发送 spot 收到的量（运输矩阵按发送方求和）。受体层面把该受体的所有配体加起来。
- **靶基因得分**：靶基因归一化表达（normalize_total + log1p）的平均值。
- **三个指标**：
  - **原始 Spearman**：所有 spot 上接收信号对靶基因得分的 Spearman，不扣受体；
  - **偏 Spearman**：在秩上控制受体表达的偏相关，即两者的秩分别对受体表达的秩回归，取残差的相关；
  - **只用受体表达**：受体表达对靶基因得分的 Spearman，与条件无关。
- **靶基因规则**：
  - **主规则**：KEGG + REACTOME 的 PPR，每个受体取前 10 个 TF；靶基因在 ≥5% spot 中检出，至少 5 个；去掉 LR 基因。
  - **COMMOT 规则**（第 8.8 节）：只用 REACTOME，PPR ≥ 1e-5 的全部 TF；只取高变基因；不设检出比例和最少个数。
- **单位**：
  - 主表是**受体层面**，只用"共同受体集"，即在 C、B、A×4、F、I 中都有定义的受体（后部 137 / 76 个，前部 143 / 86 个；C726 在这一集合上也全部有定义）。
  - 第 4 节另给 **LR 对层面**，这一层与原文的单位相同。
- **区间**：对受体（或 LR 对）有放回重抽样 1000 次，`numpy.random.default_rng(1)`，取 2.5% 和 97.5% 分位数。均值和中位数用同一组重抽样。做法与 `r0_validation.py` 相同。
  - 核对：后部 A(r₀=50) 的偏 Spearman 均值 0.048 [0.037, 0.062]，与 `reports/stage2_r0val_post/curve.csv` 一致。
- 只报告效应大小，不给 p 值（spot 之间有空间自相关）。

### 3.3 两张切片共同的观察（描述性，不是预先登记的判断）

- 各条件的**原始 Spearman 几乎相同**（后部中位数 0.136–0.138，前部 0.093–0.095），而且只比"只用受体表达"高一点。
  也就是说，原始 Spearman 的大部分来自受体表达本身，不能区分不同的运输方案。
- 扣掉受体表达后，**偏 Spearman 只剩 0.01–0.05**；各条件之间的差别都在区间重叠的范围内，与 r₀ 验证报告的结论一致。
- 共同受体集之外，C 和 C726 比其他条件多 1–5 个有定义的受体（例如前部主规则 148 对 143），表中没有计入。

## 4. 原文报告的数值与定义

**来源**：Cang et al., *Nat Methods* 20, 218–228 (2023), doi:10.1038/s41592-022-01728-4。
- 正文全文取自 Europe PMC（PMC9911355，`data/literature/commot_epmc/`）；
- 补充材料 PDF 取自出版社（`41592_2022_1728_MOESM1_ESM.pdf`，SHA256 `10843eb5…6b32`，`data/literature/commot_supp/`）；
- 两者都不进版本库。

**原文数值（spot 层面）。** 结果一节 "Robust identification of CCC direction and downstream target"：

> "At the individual-spot scale, Spearman's correlation coefficient was computed for each ligand–receptor pair between the received signal and the average expression of the known downstream genes. The median correlations on the three datasets were 0.237, 0.180 and 0.230, respectively (Supplementary Fig. 21)."

- 三个数据集依次是 Visium 人乳腺癌、**Visium 鼠脑（0.180）**、seqFISH+。
- 补充图 21 的图注：每个点是一个 LR 对，箱线图；样本量 n = 192、**164**、519 个 LR 对。
- Zenodo 代码（`cell-level_downstream_gene_correlation.ipynb`，见 `reports/commot_repro_check.md`）的输出与此一致：
  鼠脑 164 对，均值 0.1968（代码打印 "average: 0.19681672570590536"）。

**聚类层面**（补充图 22–23，与 CellChat、Giotto、CellPhoneDB v3 比较）：鼠脑 n = 84 / 83 对。
原文只给箱线图，正文和图注里没有数值，所以这里不列；本研究也没有做聚类层面的评价。

**指标定义在原文中的位置：**
- 方法部分 "Evaluation metrics" 只定义了聚类层面的版本：各聚类的平均接收信号，对靶基因中差异表达基因比例的 Spearman。
- spot 层面的定义只出现在结果正文和补充图 21 的图注里。

**原文的鼠脑设置（从 Zenodo 代码核对）：**
- 切片是 `V1_Mouse_Brain_Sagittal_Posterior`，3355 个 spot。
  原文 Data availability 写的是 "sagittal posterior"，但给的链接是前部切片的页面，以代码为准。
- LR 库是 COMMOT 自带的小鼠 CellChatDB：1209 对；`filter_lr_database(min_cell_pct = 0.05)` 后剩 250 对。
  原文说只用 "secreted" 配体的配对。
- `dis_thr = 1000`，`heteromeric = True`，默认 COT 参数。
- 靶基因按第 8.8 节所述规则，但：
  - 靶基因得分是**高变基因原始计数**的平均（没有 log1p）；
  - Spearman 为 NaN 的记为 0；
  - 用全部 spot。

### 4.1 与我们复现的 C 对比

最接近原文的口径是：后部切片，COMMOT 靶基因规则，LR 对层面，只取分泌型配对。

| | 原文（补充图 21） | 本研究 C（363 µm） | 本研究 C726（726 µm，同原文截断） |
|---|---|---|---|
| LR 对数 | 164 | 164 | 164 |
| 原始 Spearman 中位数 [95% CI] | **0.180** | 0.141 [0.126, 0.150] | 0.144 [0.124, 0.156] |
| 原始 Spearman 均值 | 0.197（Zenodo 输出） | 0.146 | 0.146 |
| 同口径的偏 Spearman 中位数 / 均值 | 原文没有 | — | 0.026 / 0.041 |
| 同口径的只用受体表达中位数 / 均值 | 原文没有 | — | 0.141 / 0.136 |

- 加上接触型配对后，C 是 201 对，中位数 0.137；C726 是 0.142。本研究这一口径下没有 NaN，"去掉 NaN"和"NaN 记 0"结果相同。
- 两边的 164 对是巧合：配对来自不同版本的 CellChatDB，不是同一批配对。

**结论：两者的定义不完全一致，数值也对不上。** 原文中位数 0.180 落在我们 C726 的区间 [0.124, 0.156] 之外。差别有以下几处：

| 项目 | 原文 | 本研究 C / C726 | 一致？ |
|---|---|---|---|
| 切片 | 后部 | 后部 | 是 |
| 指标 | 每个 LR 对的原始 Spearman，spot 层面，取中位数 | 同（第 4.1 节表）；主表是受体层面加偏 Spearman | 第 4.1 节的口径一致 |
| 截断 | 1000 像素 | C：500 像素；C726：1000 像素 | C726 一致 |
| OT 参数 | COMMOT 默认（ε = 0.1，ρ = 10，四方案混合） | 同 | 是 |
| LR 库 | COMMOT 自带 CellChatDB 小鼠（v1），只用分泌型 | CellChatDB v2，分泌型 + 接触型（4.1 节只取分泌型）；按 5% 过滤 | **否**（版本不同） |
| 受体 → TF → 靶基因 | REACTOME PPR ≥ 1e-5，TRRUST + RegNetwork，高变基因 | 同（第 8.8 节） | 是。复合物匹配有差别：本研究按亚基集合匹配 |
| 靶基因得分 | 高变基因**原始计数**的平均 | normalize_total + log1p 的平均（第 8.8 节有意不跟随） | **否** |
| NaN | 记为 0 | 本口径没有 NaN | — |

- 两处"否"哪一处造成了 0.180 和 0.14 的差距，现有结果分不出来。
- 要分清楚，需要换靶基因得分的尺度或换 LR 库重新评价。这属于新的分析，按规则需要你先决定并登记；本次没有做。
