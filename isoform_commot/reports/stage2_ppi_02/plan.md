提交前不运行任何带 S 的 OT,也不做任何带 S 的靶基因评价。

**依据:**
- 注入实验 01(`reports/stage2_inject_01/results.md`,提交 3fe83b3):按结论表进入真实切片检验。

## 0. 问题

三种做法:**不加 S**(S = 1,即现在的 Stage 2);**原始 S**(V12 分数);**老师的 S′**(每个配体内归一化:S′ = S / Σ S,对该配体在本切片面板中的所有受体求和)。

- **D1 信息:** 原始 S、S′ 各自是否带有配对信息?比较对象是同类型内打乱的分数(分布相同,对应关系被破坏)。
- **D2 改进:** 原始 S、S′ 各自是否比不加 S 更好?
- **D3 两种 S 的比较:** 原始 S 与 S′ 哪个更好?

**预先记录的预期**(来自注入实验的探索性结果):在 V12 的质量(约 0.75)下,合成数据上受体层指标相对 S = 1 约为 −0.01,
相对打乱为正。所以 D2 预计为"未改进",D1 有可能成立;注入实验中 S′ 的合并增益在各质量档都低于原始 S,所以 D3 预计原始 S 不差于 S′。
真实评价的分辨率也在这个量级:Stage 2 坐标打乱对照的差只有 0.0095(区间 0.0029–0.0163,`stage2_plan.md` 第 9.11 节)。

## 2. cost 与参数

- C = −log F(d) − β·log S_eff,S_eff 为原始 S 或 S′;r₀ = 50 µm,扩散截断 363.08 µm,其余同 Stage 2 条件 A;stopthr 1e-11。
- **β 在看任何真实评价之前,从注入实验中按 R3 的规则选定**(种子 1 选,种子 2、3 确认;取不高于 V12 区间下限 0.730 的最近一档,即 0.7 档):

  | 设置 | 原始 S | S′ |
  |---|---|---|
  | 主设置 ε = 0.2、ρ = 1 | β = 1 | β = 0.2 |
  | 次设置 ε = 0.1、ρ = 10 | β = 1 | β = 1 |

  主设置下 S′ 在 0.8 档选出的是 β = 1,所以另跑一次 S′、β = 1,作为敏感性分析(只报告相对不加 S 的 Δ)。
- **主设置(用户决定,11-19):ε = 0.2、ρ = 1**,nitermax 50,000,CPU,固定版本 COMMOT 求解器。
- **次设置:ε = 0.1、ρ = 10**,nitermax 50,000,GPU(`gpu_unot.py`,注入实验修订 01 的移植)。收敛按 `stage2_plan.md` 第 8.7 节。
  - **只做 D2、D3,不做打乱(D1)。** 整张切片约 460 万个元素,这个设置下每次求解要跑满 5 万次迭代,在 GPU 上估计要几十分钟;
    做几十次打乱要一天以上。注入实验也显示这个设置下 S 很难起作用。
  - **稳定性诊断:** 后部的原始 S 和 S′ 两个条件另用 200,000 次重跑,标准同 8.7:每个受体的相对 L1 ≤ 1e-3、Spearman ≥ 0.999,总运输量相对差 ≤ 1e-3。
    不满足则次设置记为"无法判定"。
- **收敛(两种设置):** 求解器的质量守恒和 KKT 检查通过;到上限只记录(第 8.7 节)。
- r₀ = 50 µm 是在 ε = 0.1、ρ = 10 下选出的;主设置沿用,不重新选择。

## 3. 条件(每张切片)

| 代号 | S | 设置 | 用途 |
|---|---|---|---|
| `no_ppi` | S = 1 | 两种 | 不加 S。次设置下与 Stage 2 条件 A(r₀ = 50)相同,这里用同一流程重新计算 |
| `raw` | V12 `s_raw` | 两种 | 原始 S |
| `snorm` | S′ = S / Σ S(同一配体的所有受体) | 两种 | 老师的 S′ |
| `uniform` | 1/k(k 为该配体的受体数),β 同 S′ | 两种 | 描述性对照,不带配对信息 |
| `raw_perm_k` | V12 分数在同类型(扩散 / 接触)、有分数的配对之间打乱,种子 k = 1, …, 100;复合物按整体分数打乱 | 主设置 | 原始 S 的零分布 |
| `snorm_perm_k` | 同一次打乱后再按配体归一化 | 主设置 | S′ 的零分布 |
| 第 5 节各项 | — | 主设置 | 敏感性分析 |
| `raw_n200k`、`snorm_n200k` | 同 `raw`、`snorm`,200,000 次迭代 | 次设置,只有后部 | 稳定性诊断 |

**无分数的配对:** 在所有条件中都取该切片同类型有分数配对的原始 S 中位数,不参与打乱;S′ 在填补之后再计算。
不填 S = 1,因为 −log 1 = 0 的 cost 最低,等于给这些配对最大的优待。

## 4. 指标与判定(每种设置分别计算,以主设置为准)

- **M:** 共同受体集合上受体层偏 Spearman 的平均值。共同受体集合指该切片、该设置下全部核心条件和打乱条件中偏 Spearman 都有定义的受体;报告个数。
- **D1(只在主设置;原始 S、S′ 分别判定):** p = (1 + #{M_perm ≥ M}) / (1 + N)。后部 p ≤ 0.05 为"有信息";前部同样满足为"确认"。
  同时报告 M_perm 的平均值和标准差,作为评价噪声的直接估计。
- **D2(分别判定):** Δ = 共同受体上(该 S − `no_ppi`)偏 Spearman 差的平均值,对受体做 bootstrap(1000 次,`numpy.random.default_rng(1)`)。
  95% 区间下限 > 0 为"改进",上限 < 0 为"变差",其余为"不确定"。
- **D3:** Δ = 共同受体上(`raw` − `snorm`)的平均差,bootstrap 同上。下限 > 0 为"原始 S 更好",上限 < 0 为"S′ 更好",其余为"无法区分"。
- **后部判定,前部用同一规则确认。** 两者相同为"确认";不同时如实报告两者,不合并。
- **失败:** 某个核心条件(`no_ppi`、`raw`、`snorm`、`uniform`)求解检查不通过,则该切片、该设置记为"无法判定";打乱条件失败则剔除并报告,N 相应减少。

| D1 | D2 | 该种 S 的结论 |
|---|---|---|
| 有信息 | 改进 | 在本评价下,这种 S 改进了推断 |
| 有信息 | 不确定或变差 | 带有配对信息,但目前不足以改进推断(注入实验的预期) |
| 无信息 | — | 在本评价下看不出配对信息;对照 M_perm 的标准差与预期效应,判断是 S 无信息还是评价分辨不出 |

次设置没有 D1,只报告 D2、D3。

## 5. 敏感性分析(只做主设置、两张切片;描述性,不判定)

1. 长配对(最佳亚基对的两条序列合计超过 1600 aa,即超过 1603 token)改用同类型中位数;
2. 同源互作配对改用同类型中位数;
3. 去掉无分数的配对(面板变小,`no_ppi` 在同一面板上重新计算,即 `no_ppi_scored_only`);
4. 评价规则改用前 5、前 20 个 TF;
5. S′ 取 β = 1(第 2 节)。

每项对原始 S 和 S′ 都做(第 5 项只有 S′),只报告相对对应的 `no_ppi` 的 Δ 和 bootstrap 区间,不做打乱。

## 6. 实现

- `stage2_s.py`:`cases` 列出条件,`run` 求解并立即评价,`equivalence` 是等价门槛,`summarise` 给出判定。
  求解后直接计算受体层接收信号(`plans.received_signal`),并用 `evaluate_targets.py` 中的同一组函数计算偏 Spearman。
  不保存完整运输矩阵(整张切片约 460 万个元素);非打乱条件保存受体 × spot 的接收信号,用于稳定性诊断。
- **CPU 等价门槛(运行前):** 后部、主设置的 `no_ppi` 和 `raw` 另存完整 case 文件,用 `evaluate_targets.py run` 原样评价,
  与本脚本逐受体比较偏 Spearman(前 10 个 TF、平均表达),差 ≤ 1e-12 且缺失位置相同,否则停止。
- **GPU 等价门槛(次设置运行前):** `gpu_unot.py equivalence` 在后部整张切片(ε = 0.1、ρ = 10,不加 S)上与固定版本求解器各跑 200 次固定迭代,最大相对差 ≤ 1e-9。
- 失败的求解记录错误,不中断其余条件;中断后加 `--resume`,已完成的条件跳过。

## 8. 已知局限

1. 评价用的是靶基因表达的间接证据,分辨率约 0.01。
2. V12 对输入顺序敏感(同一对蛋白 A→B 与 B→A 的分数可以相差很大),现有分数取两个顺序的平均值。
3. β 来自合成数据上的选择,不保证在真实数据上最优;本实验不在真实数据上调 β,避免用评价结果选参数。
4. 实验一显示 V12 在一般 PPI 上的整体区分能力不高(AUROC 约 0.68–0.72),在 LR 长配对上更低。
