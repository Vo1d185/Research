# 实验三(affinity_01)预注册计划:BindPred 能否给出可用作 S 的结合强度

写于任何打分之前。本计划提交后才允许正式运行。

## 0. 背景与问题

- 实验二(`reports/stage2_ppi_02/results.md`,结果提交 8c84095)的结论:PLM-interact humanV12 的互作分数,
  在 CellChatDB 已确认的配对之间不带可用的配对信息,真实 S 不如同类型内打乱的 S。
- 诊断:V12 的训练标签是二值的(互作 / 不互作),它输出的是互作概率,不是解离常数 Kd。
- 方法需要的是 Kd。按质量作用定律,配体 A 在受体 B、C 之间的结合比例为
  `[B]/Kd(A,B) : [C]/Kd(A,C)`;COMMOT 用基因表达近似浓度,缺的是 1/Kd。
  令 `S ∝ 1/Kd`,则 `−log S = log Kd + 常数`,cost 中的 S 项与结合自由能成正比。
- 本实验的问题:**BindPred(直接回归 log10 Kd)在配体-受体对上,能否正确排出同一受体的多个配体之间、
  同一配体的多个受体之间的亲和力顺序?** 只有通过本实验,才进入带 S 的 OT。

本实验只打分、不做 OT。

## 1. 打分器

| 名称 | 说明 |
|---|---|
| `bindpred` | BindPred 通用模型 `ESM2_BindPred.cbm`(hbp5181/BindPred,修订 89a595d1,MIT)。输入为冻结 ESM-2 650M 的序列向量:取残基位置的平均,超过 1022 个残基的部分截断,配体在前、受体在后拼成 2560 维;CatBoost 输出 log10 Kd。定义预测值 `pKd_hat = −log10 Kd_pred` |
| `v12` | PLM-interact humanV12(基线)。用 `plm_score.py score`,设定与实验一、二相同 |
| `length` | 配体序列长度(平凡基线) |

**输入顺序已核实:** BindPred 对两条序列的顺序敏感。在其公开训练表上,配体在前时 Pearson 为 0.926,
受体在前为 0.696。本实验一律配体在前。

**向量复算已核实:** 用 transformers 的 `EsmModel` 复算 4 行(含 1 条长于 1022 残基的受体)的向量,
与训练表中的数值最大差 3e-6。

## 2. 测评集

**来源:** IUPHAR/BPS Guide to Pharmacology(GtoPdb)2026.3.1(2026-10-12 发布),
`interactions.csv` 与 `peptides.csv`;受体序列取 UniProt 2026_04 的 canonical 全长。
三份输入文件连同 sha256 一并提交在 `reports/affinity_01/inputs/`。

**纳入条件(全部满足):**

1. `Endogenous` 为 true(机体自身的配体);
2. `Ligand Type` 为 Peptide;
3. `Affinity Units` 为 pKd 或 pKi(结合常数;pEC50、pIC50 为功能活性,排除);
4. 靶点为单个基因(`Target UniProt ID` 不含 `|`,即排除需要多个亚基的受体);
5. 配体在 `peptides.csv` 中有单字母序列,长度 ≥ 5,且仅含 20 种标准氨基酸
   (焦谷氨酸记号 `X` 统一改为 `Q`,改动数目记录在 `dataset.json`);
6. 同一(物种,受体,配体)有多条记录时,取实测值的中位数,记录条数。

**排除训练集泄漏:** BindPred 训练表(`embeddings_only.csv`,12,062 行)公开。对测评集中的每条序列,
用局部比对(BLOSUM62,开罚 −10、延罚 −0.5)在训练表的全部序列中查找覆盖率 ≥ 90% 的匹配
(一致残基数 ≥ 0.9 × 两条序列的较短长度)。若某一对的配体与受体分别匹配到训练表中**同一行**的两条序列,
该对判为泄漏并排除。单侧蛋白见过但配对未见过的,保留并在结果中按 `lig_seen`、`rec_seen` 分层报告。

**预先清点的规模(用本脚本 `prepare` 在本机跑出,未打分):** 条目 24,968 条 → 天然配体 1,683 → 肽类 876 →
结合常数 308 → 单基因靶点 297 → 配体序列合格 280(其中 7 条焦谷氨酸改名)→ 按(物种,受体,配体)合并 255 对 →
排除泄漏 8 对,余 **247 对**(人 171、小鼠 24、大鼠 52),116 个受体;单侧见过的:配体 15、受体 10;
受体序列超过 1022 残基需截断的 7 个,配体 1 个。
可用组:同一受体 ≥3 个配体的 **35 组共 145 对**,组内实测值差的中位数 2.3;同一配体 ≥3 个受体的 26 组共 90 对。
正式运行以脚本输出为准,与此处不一致时如实报告。

## 3. 主要指标

- **组内 Spearman:** 对每个"同一受体、≥3 个配体"的组,计算预测 `pKd_hat` 与实测 pKd 的 Spearman 相关;
  **ρ̄ = 各组的平均值**(每组等权)。这是主要指标,对应"同一配体在多个受体之间如何分配"所需的相对顺序。
- **自助区间:** 以组为单位重抽 1000 次(`numpy.random.default_rng(1)`),报告 95% 区间。
- 同时报告"同一配体、≥3 个受体"的组内 Spearman(次要指标,同样规则)。

## 4. 判定标准(预先登记)

| 编号 | 判定 | 通过线 |
|---|---|---|
| A1 | 有排序能力 | ρ̄ 的 95% 区间下限 > 0 |
| A2 | 效应量 | ρ̄ ≥ 0.30 |
| A3 | 超过基线 | ρ̄(bindpred) − ρ̄(v12) 与 ρ̄(bindpred) − ρ̄(length) 的配对自助 95% 区间下限均 > 0 |

- 自助在同一组重抽上同时计算三种打分器,以便做配对比较。
- **基线的方向:** `v12` 按"分数越高亲和力越高"取正号。`length` 的方向无先验,取两种符号中较有利的一个
  (等价于对各组平均值取绝对值),对 BindPred 更严格。
- 为什么是 0.30:实验二的评价分辨率约 0.006–0.01(`stage2_ppi_02/plan.md` 第 0 节),
  而 OT 的分配依赖相对顺序;ρ̄ 低于 0.3 时,同一受体的配体之间顺序已有近一半出错,
  再进 OT 没有意义。此数值为本项目自定,不是文献标准。

**结论表:**

| A1 | A2 | A3 | 结论 |
|---|---|---|---|
| 通过 | 通过 | 通过 | BindPred 的预测可作为 S 进入 OT(另写实验四) |
| 通过 | 不通过 | — | 有排序能力但效应量不足;记录 ρ̄,不进入 OT |
| 通过 | 通过 | 不通过 | 效应量足够但不优于基线;需先查清基线为何同样有效 |
| 不通过 | — | — | 在本测评集上看不出排序能力,不进入 OT |

**失败处理:** 打分出错、向量复算不符、或可用组数少于 10 组,则本实验记为"无法判定",如实报告。

## 5. 同时报告(描述性,不判定)

1. **绝对精度:** 预测 log10 Kd 与实测值的均方根误差和系统偏差(平均预测减平均实测)。
   用作 S 时,同一配体内部的常数可被归一化消掉,所以绝对值只作参考。
2. **分层:** 按物种(人 / 小鼠 / 大鼠)、按单侧见过(`lig_seen`、`rec_seen`)、
   按配体长度(≤ 20、21–50、> 50 个残基)分别报告 ρ̄。
3. **合并相关:** 全部配对放在一起的 Pearson 与 Spearman(与论文报告的口径一致,便于对照;
   但不同受体之间的 Kd 差异会抬高这个数值,不作为判定)。
4. **组内范围:** 每组实测 pKd 的最大最小之差,以及"差值 ≥ 0.5 个数量级"的配对数。
5. **V12 与实测值的关系:** V12 分数与 pKd 的组内 Spearman(检验实验二的诊断是否成立)。

## 6. 已知限制(写在前面)

- **受体序列与训练分布不符。** BindPred 训练集的受体序列取自已解析结构的链,多为胞外域等构建体;
  本实验用 UniProt canonical 全长,7 个受体超过 1022 个残基、会被截断。这会低估它的实际能力。
- **测评集以 GPCR 配体为主**,而训练集(SKEMPI、SAbDab、PDBbind、Affinity Benchmark、ATLAS)
  以抗体–抗原、酶–抑制剂、TCR–pMHC 为主,GPCR 复合物很少。本实验测的正是"换一类蛋白后还准不准"。
- **pKi 与 pKd 混用。** pKi 来自竞争结合实验,pKd 来自直接结合实验,两者量纲一致但不完全等价。
  组内分层报告,不单独判定。
- **MINT 版本未测。** 论文中 MINT 与 ESM2 版本差 0.003,本实验只测公开的 ESM2 版本。
- **不检验 BindPred 的训练过程**,只用其公开权重做推断。
