# 实验四(bindpred_ot_01)预注册计划:BindPred 的 S′ 进入 OT

写于任何带 BindPred 分数的 OT 求解之前。本计划提交后才允许正式运行。

## 0. 背景、动机与如实说明

- 实验三(`reports/affinity_01/results.md`,结果提交 4f78754)的预注册主要指标不通过:同一受体的多个配体之间,
  BindPred 排不出实测亲和力顺序(ρ̄ = +0.050,95% 区间 [−0.161, +0.253])。按其计划,结论为"不进入 OT"。
- 同一实验的次要指标(同一配体、≥3 个受体,26 组)为 +0.474 [+0.277, +0.668]。事后分析显示,
  这个信号主要来自"受体整体偏移":只用 BindPred 对该受体其他配体的预测平均值,就能得到 +0.421。
- 老师的 S′ = S / Σ_R S 在每个配体内部归一化,保留的正是"同一配体在不同受体之间的相对大小",即 BindPred
  唯一显示出信号的方向。
- **本实验是在看过实验三结果之后、由用户决定进行的。**动机来自事后分析,所以结论只能视为对一个事后假设的检验;
  判定标准在这里先写定,看过结果后不改。

## 1. 模型与参数

cost:`C = −log F(d) − log S_eff`,F(d) = r₀/(r₀+d)。用户已决定去掉 β(β 固定为 1)。

| 项目 | 取值 |
|---|---|
| OT | `stage2_s.py run --setting main`,代码不改:ε = 0.2、ρ = 1、r₀ = 50 µm、扩散截断 363.0757 µm(实验二修订 01)、最多 50,000 次迭代、stopthr 1e-11、CPU |
| 切片 | 后部 `stage2_input_post` 判定,前部 `stage2_input_ant` 确认(与实验二相同) |
| 评价 | 受体层偏 Spearman(前 10 个 TF,scSeqComm),与实验二相同的 `Evaluation` |
| 次设置 | 不做。实验二中 ε = 0.1、ρ = 10 的 D2 全部在 0 附近,且稳定性诊断未通过 |

## 2. BindPred 分数

1. **配对与方向:** 面板为两张切片 `lr.csv` 的并集。亚基组合与实验二的 V12 打分相同(`stage2_ppi.subunit_pairs`),
   **配体亚基在前、受体亚基在后**(实验三已核实 BindPred 对顺序敏感)。
2. **序列:** UniProt 2026_04 canonical 全长,冻结在 `inputs/mouse_panel_sequences.tsv`;
   384 条序列逐条与实验二 `protein_map.csv` 的 sha256 核对一致。超过 1022 个残基的部分按 BindPred 的做法截断。
3. **向量与预测:** 与实验三相同(`affinity.py embed/predict`,冻结 ESM-2 650M,残基平均,CatBoost)。
4. **一对配体-受体的分数:** 各亚基组合中 pKd_hat 最高的一个(与 V12 取最高分的规则相同)。
   S = 10^(pKd_hat − 10),即以 10¹⁰ M⁻¹ 为单位的 1/Kd;进入 OT 的只有 S′,单位在归一化时消掉。
5. **无分数的配对**(有亚基映射不到蛋白,与实验二相同的那些):S 取同类型(扩散 / 接触)有分数配对的中位数,
   再做归一化。打乱时不参与打乱(与实验二相同)。
6. **S′ = S / Σ_R S**,对该配体在本切片面板中的全部受体求和。

## 3. 条件(每张切片)

| 名称 | S_eff | 用途 |
|---|---|---|
| `no_ppi` | 1 | 不加 S |
| `bp_snorm` | BindPred 的 S′ | 主要条件 |
| `uniform` | 1/k(k 为该配体的受体数) | 只有归一化、没有排序信息的对照 |
| `bp_snorm_perm_001`–`100` | 同类型内打乱有分数配对的 S(种子 1–100),再归一化 | D1 的零分布 |
| `bp_receptor_snorm` | 每个受体取其全部面板配对的 BindPred 平均 pKd_hat,再归一化 | 敏感性:只有"受体整体偏移" |
| `v12_snorm` | V12 的 S′(β = 1) | 敏感性:与实验二 `snorm_b1` 相同,用作参照和复现门槛 |

每张切片 105 个条件,共 210 个。按实验二的实测速度(主设置每个条件约 10 秒、8 个并行),约 5–10 分钟。

**`bp_snorm` 与 `uniform` 的区别:** −log S′ = −log(1/k) − log(k·S′)。第一项两者相同,
是"受体多的配体整体 cost 更高"的部分(实验二中 S′ 的改进可以由它完全解释);第二项只存在于 `bp_snorm`,
是 BindPred 在同一配体的受体之间做的重新分配。**F2 比较的就是第二项有没有用。**

## 4. 判定(预先登记)

共同受体集合:该切片中全部核心条件与打乱条件的偏 Spearman 都有定义的受体;报告个数。M 为共同受体上的平均值。

- **F1 信息:** p = (1 + #{M_perm ≥ M(bp_snorm)}) / (1 + N),N = 100。后部 p ≤ 0.05 为"有信息";前部同样满足为"确认"。
  同时报告 M_perm 的平均值与标准差。
- **F2 超过平均分配:** Δ = 共同受体上(`bp_snorm` − `uniform`)的平均差,对受体做 bootstrap
  (1000 次,`numpy.random.default_rng(1)`)。95% 区间下限 > 0 为"改进",上限 < 0 为"变差",其余为"不确定"。
- **F3 相对不加 S:** Δ(`bp_snorm` − `no_ppi`),规则同 F2。只报告,不进入结论表。

| F1 | F2 | 结论 |
|---|---|---|
| 有信息 | 改进 | BindPred 的 S′ 改进了推断,且超过平均分配 |
| 有信息 | 不确定或变差 | 带有信息,但不超过平均分配 |
| 无信息 | — | 看不出 BindPred 的配对信息 |

后部判定、前部确认;两者不同时如实报告,不合并。

**失败:** 核心条件(`no_ppi`、`bp_snorm`、`uniform`)求解检查不通过,该切片记为"无法判定";
打乱条件失败则剔除并报告,N 相应减少。

**预先记录的预期:** 不作方向性预测。实验三的信号只在 26 组、只来自受体整体偏移;
而实验二中 V12 的 S′ 在两张切片上都不如打乱。

## 5. 敏感性分析(描述性,不判定)

1. `bp_receptor_snorm` 相对 `uniform`,以及 `bp_snorm` 相对 `bp_receptor_snorm`:
   信号是否完全来自受体整体偏移;
2. `v12_snorm` 相对 `uniform`、`bp_snorm` 相对 `v12_snorm`;
3. F2、F3 在前 5 个与前 20 个 TF 下的结果;
4. 打分本身:BindPred 预测值的分布,同一配体内部的预测差(中位数、小于 0.1 个 log 单位的配体数)。

## 6. 复现门槛

正式求解前,先跑两个条件并与实验二已提交的受体值(`reports/stage2_ppi_02/summary/*_main_receptor_partial_spearman.csv`)
逐受体比较:

- `no_ppi` 对实验二 `no_ppi`;
- `v12_snorm` 对实验二 `snorm_b1`。

两张切片、两个条件的最大差都 ≤ 1e-10,且缺失位置一致,才继续。不通过就停下汇报。

## 7. 已知限制

- 动机来自事后分析(第 0 节);实验三的次要指标只有 26 组,且受体整体偏移部分也可能来自测量批次。
- 面板序列是含信号肽的全长;BindPred 训练用的是已解析结构中的链。
- 实验三的测评集只有肽类配体;面板中大量配体是较大的蛋白,BindPred 在这类配体上未经检验。
- 与实验二相同,评价是间接的(受体信号与下游靶基因的一致性),分辨率约 0.006–0.01。
