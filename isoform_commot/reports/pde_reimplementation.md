## 依据

- **方程：** COMMOT 补充材料 Supplementary Note §2.1 Eq. (19)，与 Extended Data Fig. 1a 中的方程相同
  （补充材料 PDF：Springer 静态链接 `41592_2022_1728_MOESM1_ESM.pdf`，SHA256 `10843eb5…6b32`；Extended Data Fig. 1：`41592_2022_1728_Fig6_ESM.jpg`；
  两者存放在 `data/commot_paper_si/`，不进版本库）：

  ∂[Lᵢ]/∂t = Dᵢ∇²[Lᵢ] − Σⱼ aᵢⱼ[Lᵢ][Rⱼ] + Σⱼ bᵢⱼ[LᵢRⱼ] − cᵢ[Lᵢ]（+ pᵢ(x)，见下）
  ∂[LᵢRⱼ]/∂t = aᵢⱼ[Lᵢ][Rⱼ] − bᵢⱼ[LᵢRⱼ]
  ∂[Rⱼ]/∂t = −Σᵢ aᵢⱼ[Lᵢ][Rⱼ] + Σᵢ bᵢⱼ[LᵢRⱼ]

- **数值设置（补充材料 §2.2）：** 无通量边界，2D 50 × 50 网格，py-pde（scipy RK45）。
- **参数（Zenodo 存档 `pde_model_comparison.zip`，见 `reports/commot_repro_check.md`）：** D = 200，a = 1，b = 0.001，c = 0.2；
  受体、复合物不扩散、不降解；网格为 [−200, 200]² 上的格心网格（存档 `grid.npy` 与之完全一致）。

## 与论文文字不一致、按存档实现的地方

1. **配体有恒定的产生项 pᵢ(x)。** Eq. (19) 和图中的方程都没有这一项，补充材料 §2.2 写的是"配体和受体的初始分布由多个高斯生成"。
   但存档的模拟在 t = 0 时游离配体处处为 0，之后逐渐积累（case 1 sim 1：配体 1 总量 0 → 532 → 851 → … → 1393），
   而文件名为 `ligand_prod_i.npy` 的场只作为产生速率出现；受体在 t = 0 时等于 `receptor_init_j.npy`，复合物为 0。
   补充材料 §2 的例子也说配体的"产生速率来自空间数据"。没有产生项时配体只会衰减，复合物最终全部解离，不存在非零稳态。
2. **"计算到平衡"：** §2.2 说模拟运行到复合物达到数值平衡；存档的 100 次模拟都在 t = 50 停止（`stop_reason: Reached final time`）。
   t = 50 时受体基本被占满，复合物总量变化很小，但离真正的稳态还有距离（见下）。

## 模型与求解

- 格心网格，二阶差分拉普拉斯，边界用等于边界值的虚拟格点（零通量）；时间积分用 `scipy.integrate.solve_ivp`。
- **稳态的解析形式**（复合物与受体不降解时）：稳态下每个配对的结合与解离平衡（a L R = b C），所以游离配体满足线性方程
  (cᵢ − Dᵢ∇²) Lᵢ = pᵢ，与受体无关；令 Kᵢⱼ = aᵢⱼ / bᵢⱼ，受体按 Rⱼ = R⁰ⱼ / (1 + Σᵢ Kᵢⱼ Lᵢ) 分配，Cᵢⱼ = Kᵢⱼ Lᵢ Rⱼ。
  `steady_state()` 用这个形式（稀疏线性求解）；`run_to_steady_state()` 用 LSODA 长时间积分，两者互相独立。
- **测试（`test_simulation.py`，6 个）：** 拉普拉斯零通量且与矩阵形式一致；受体 + 复合物逐点守恒（右端精确为 0）；
  解析稳态代入右端残差 < 1e-9；长时间积分收敛到解析稳态（相对差 < 1e-5）；对称情形的两个复合物互为镜像；
  位置偏置时较近的配体、扩散更快时扩散更快的配体占据更多受体。

|---|---|---|---|---|---|
| case 2 sim 1 | 4 | 1.8e-7 | 1.5e-6 | 1.000000 | 0.41 |
| case 6 sim 1 | 10 | 1.4e-6 | 1.4e-6 | 1.000000 | 0.16 |

**case 1 的差别来自存档本身。** Eq. (19) 中受体 + 复合物的总量严格守恒（Runge–Kutta 方法也精确保持这种线性守恒量），
本实现的守恒误差为 1e-16。存档的全部 100 次模拟中（`archive_conservation.csv`）：

| 存档情形 | 运行日期（py-pde 记录） | 受体 + 复合物总量的最大相对漂移 |
|---|---|---|
| case 1（10 次） | 2021-03-09 | 最大 3.1e-2，10 次都 > 1e-6 |
| case 2–10（90 次） | 2021-03-10 | ≤ 1e-15 |

case 1 早一天运行，它的求解代码显然与之后的版本不同（存档中没有求解器代码，无法确定差别）；
本实现与 case 2–10 的版本一致到 1e-6 以内。

## 复现 Extended Data Fig. 1 的示例（定性）

参数同存档（D = 200，a = 1，b = 0.001，c = 0.2；衰减长度 λ = √(D/c) ≈ 31.6）。图中没有给出例子的具体位置和形状，
下面的布局按图估计；比较的是形状和相对大小，不是数值。

### 1D（Extended Data Fig. 1a；`example_1d.png`、`example_1d.csv`）

区间 [0, 400]，400 个格点；受体为中心 200、半宽 50 的平滑包（升余弦），配体 2 的产生区中心 100，配体 1 中心 300（半宽 50）。

| 情形 | 设置 | 配体 1 占据的受体比例（稳态 / t = 50） | 配体 2（稳态 / t = 50） | 复合物峰位置（L1 / L2） |
|---|---|---|---|---|
| 无偏 | 对称位置，D 相同 | 0.499 / 0.499 | 0.499 / 0.499 | 210.5 / 189.5 |
| 位置偏置 | 配体 1 中心移到 270 | 0.677 / 0.692 | 0.321 / 0.306 | 206.5 / 185.5 |
| 配体 2 扩散更快 | D₂ = 800 | 0.332 / 0.253 | 0.667 / 0.746 | 212.5 / 194.5 |

与图的定性对比：
- **无偏：** 两种复合物互为镜像，各占受体靠近自己配体一侧的一半。与图一致。
- **位置偏置：** 较近的配体占据大部分受体，另一种只剩靠近自己一侧的一个小峰。与图一致；图中看起来移动的可能是受体而不是配体，两者效果相同。
- **配体 2 扩散更快：** 配体 2 占据大部分受体，配体 1 的复合物缩小并偏向它自己一侧。与图一致。
- **t = 50 与稳态不同：** t = 50 时较近或扩散较快的配体占得更多，它的复合物峰也更高。因为 b = 0.001，靠解离重新分配受体的时间尺度约为 1/b = 1000。
  图中用的是哪个时刻无法从图中判断。

### 2D（Extended Data Fig. 1b；`example_2d.png`、`example_2d.csv`）

50 × 50 网格，[−200, 200]²；配体 1、2 为右侧、左侧的新月形产生区（半径 150），受体 R1、R2、R3 为中心附近的各向异性高斯，
配对 L1–R1、L1–R2、L2–R2、L2–R3（与图相同）。稳态下各配对占据其受体的比例：L1–R1 0.99，L1–R2 0.65，L2–R2 0.34，L2–R3 0.95。
与图一致的地方：三个强复合物分别落在 R1、R2、R3 上，形状与受体相同；R2 位于偏向配体 1 的一侧，所以 L2–R2 明显弱于 L1–R2。
